## Overview

**Project Title**:D&D Character Forger

**Project Description**: This app is a basic tool for D&D players to quickly make a character outline. The user inputs a character name, a race from a predefined list, and a strength score. The application then shows the name, the race chosen, and the ability score modifier calculated according to D&D 5th Edition rules.

**Project Goals**:
The goal is to create a simple and intuitive user interface for D&D character creation.

Calculating and displaying D&D 5e ability modifiers (specifically Strength).

To showcase some basic Android development concepts such as user interface interactions, basic input handling and logical operations.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Open in Android Studio
2. Sync Gradle
3. Run on Device

Instructions for using the software:

1. Select Race
2. Enter Strength Score
3. Calculate
4. View Result
